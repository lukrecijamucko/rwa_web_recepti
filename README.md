# Web aplikacija s receptima

Web aplikacija omogućuje korisnicima spremanje vlastitih recepata,
pregled recepata drugih korisnika, spremanje favorita, ocjenjivanje
recepata ocjenama od 1 do 5 te komentiranje.

Recepti pripadaju jednoj ili više kategorija te se mogu filtrirati
prema kategorijama i sastojcima. Administrator može dodavati nove
kategorije.

Aplikacija svaki dan prikazuje tri slučajna recepta iz tri različite
kategorije.
